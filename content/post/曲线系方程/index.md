# 曲线系方程
---
## 引言
> 曲线系是若干基底曲线的线性组合思想

## 1._直线系_

- ### 1.1中心直线系
直线 \( l_1, l_2 \) 相交，且  
\( l_1: A_1x + B_1y + C_1 = 0 \) 

\( l_2: A_2x + B_2y + C_2 = 0 \)  
则方程  
\[
\lambda(A_1x + B_1y + C_1) + \mu(A_2x + B_2y + C_2) = 0
\]  
可表示过 \( l_1, l_2 \) 交点的所有直线，其中 \( \lambda, \mu \in \mathbb{R} \)，且 \( \lambda  \mu \neq 0 \)。  
特别的，当 \( l_1, l_2 \) 无交点时， \( A_1  B_2 = A_2  B_1 \) 时，方程也可表示平行于 \( l_1, l_2 \) 的所有直线。  
使用时，一般不会设两个参数 \( \lambda, \mu \)，只引入一个参数 \( \mu \)，这样表示出来的方程：  
\[
A_1x + B_1y + C_1 + \mu(A_2x + B_2y + C_2) = 0
\]  
可以表示除 \( l_2 \) 以外的所有过 \( l_1, l_2 \) 交点的直线。

- ### 1.2平行直线系
直线 \( l: Ax + By + C = 0 \) 所决定的平行直线系的方程是  
\[ Ax + By + C' = 0 \]

- ### 1.3切线系

设二次曲线的一般方程为：
$$ F(x, y) = Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0 $$
如果点 $P_0(x_0, y_0)$ 在二次曲线上（即 $F(x_0, y_0) = 0$），则过该点的切线方程可以用**改写法则**直接写出：
$$ A x_0 x + B \frac{x_0 y + x y_0}{2} + C y_0 y + D \frac{x + x_0}{2} + E \frac{y + y_0}{2} + F = 0 $$
**口诀**：将原方程中的 $x^2$ 换为 $x_0 x$，$y^2$ 换为 $y_0 y$，$xy$ 换为 $\frac{x_0 y + x y_0}{2}$，$x$ 换为 $\frac{x + x_0}{2}$，$y$ 换为 $\frac{y + y_0}{2}$，常数项不变。


## 2._圆系_

方程$x^{2}+y^{2}=r^{2}$，如果$r$分别取不同值，相应可以地得到一系列不同的圆，它们具有同一个性质，都是以原点为圆心的同心圆。

对于圆的方程

$(x-a)^{2}+(y-b)^{2}=r^{2}$ 或 $x^{2}+y^{2}+Dx+Ey+F=0$

可以看出，圆一般需要三个条件a、b、r或E、D、F才能确定。

如果圆方程中，含有一个或二个任意常数时，它就表示具有某一个共同性质的所有圆。

- ### 2.1同心圆系
对于圆心为$(a, b)$的同心圆系，方程为：  
$$ (x - a)^2 + (y - b)^2 = r^2 \quad (r > 0, \, r \text{ 为参数}) $$  
圆心：$(a, b)$（固定，不随$r$变化）；  
半径：$r$（变量，$r$取不同正实数时，得到不同半径的同心圆）。  

- ### 2.2过两圆交点的圆系

\( C_1: x^2 + y^2 + D_1x + E_1y + F_1 = 0 \)，  
\( C_2: x^2 + y^2 + D_2x + E_2y + F_2 = 0 \)  
是相交两圆，则  
\(x^2 + y^2 + D_1x + E_1y + F_1 + \lambda(x^2 + y^2 + D_2x + E_2y + F_2) = 0 \)

是经过 \( C_1 \) 和 \( C_2 \) 的交点的圆系方程，其中 \( \lambda \neq -1 \) 是任意常数。

（圆系 \( C \) 不包括圆 \( C_2 \)， \( \lambda=-1 \)时为过两点的直线）

- ### 2.3共轴圆系

#### 定义
 \( C_1(x, y) = x^2 + y^2 + D_1x + E_1y + F_1 = 0 \) 

\( C_2(x, y) = x^2 + y^2 + D_2x + E_2y + F_2 = 0 \)  

则有方程  
\( \lambda_1 C_1 + \lambda_2 C_2 = 0 \)（\(\lambda_1, \lambda_2\) 是参数）

(i) 当 \(\lambda_1 + \lambda_2 = 0\) 时， \( C_1 - C_2 = 0 \)，  
即  \( (D_1 - D_2)x + (E_1 - E_2)y + (F_1 - F_2) = 0 \) 
为一直线，这条直线称为两圆的根轴.  

(ii) 当 \(\lambda_1 + \lambda_2 \neq 0\) 时，方程含有一个独立参数，\(\lambda_1, \lambda_2\) 取一系列确定的数对时，方程表示一系列圆是单参数圆族，称为共轴圆系
#### 性质（读者自证）

1.两圆的根轴必垂直两圆的连心线

2.圆系中任意两圆的根轴相同

3.根轴上任意一点至共轴圆系中任一圆的幂相等

4.若两圆相交（相切），则其根轴及圆系中的一切圆皆过两圆的交点，

若两圆不相交,则其根轴与圆系中一切圆皆不相交。

5.若三圆圆心不共线,则三圆中每两个圆的根轴共点。


## 3._曲线系_

> 须知知识

---

一般的二次曲线
$$ F(x, y) = Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0 $$
可以通过移轴和转轴化简为标准形式
\[
\begin{cases}
x = a + x' \\
y = b + y'
\end{cases}
\]

\[
\begin{cases}
x = x'\cos\theta - y'\sin\theta \\
y = x'\sin\theta + y'\cos\theta
\end{cases}
\]

---
若有两条不平行直线
$$ L_1(x, y) = A_1x + B_1y + C_1 $$
$$ L_2(x, y) = A_2x + B_2y + C_2 $$
那么方程 $$L_1(x, y)L_2(x, y)=0$$
可以表示为一个退化二次曲线，图像是 \( L_1和L_2并集 \) 

所以有结论\( L_1L_2=k \)(\( k \neq 0 \))，可以表示所有以\( L_1,L_2 \)为渐近线的双曲线

参数大小和正负决定双曲线的开口和分支

证明：

设 \( L_1(x, y)L_2(x, y)=0 \) 上有一点 \( P(x_0, y_0) \) 到\( L_1(x, y)=0距离为d_1\)

根据点到直线距离公式
$$
d_1 = \frac{|A_1 x_0 + B_1 y_0 + C_1|}{\sqrt{A_1^2 + B_1^2}} = \frac{|L_1(x_0, y_0)|}{\sqrt{A_1^2 + B_1^2}}
$$

由方程可知，在曲线上有 $L_1 = \frac{k}{L_2}$，代入距离公式得：

$$
d_1 = \frac{|k|}{|L_2(x_0, y_0)| \sqrt{A_1^2 + B_1^2}}
$$

当曲线上的点 \( P(x_0, y_0) \) 沿着曲线趋向于无穷远处时\( |L_2| \to \infty \) 
$$
\lim_{|L_2| \to \infty} d_1 = \lim_{|L_2| \to \infty} \frac{|k|}{|L_2| \sqrt{A_1^2 + B_1^2}} = 0
$$
可知\( L_1(x, y)=0 \)是图像渐近线，同理\( L_2(x, y)=0 \)也是

带入展开方程，计算判别式
$$(A_1x + B_1y + C_1)(A_2x + B_2y + C_2) = k$$
$$A_1A_2x^2 + (A_1B_2 + A_2B_1)xy + B_1B_2y^2 + (A_1C_2 + A_2C_1)x + (B_1C_2 + B_2C_1)y + (C_1C_2 - k) = 0$$

$$\Delta = (A_1B_2 + A_2B_1)^2 - 4(A_1A_2)(B_1B_2)$$
$$\Delta = (A_1B_2 - A_2B_1)^2$$
因为不平行，所以\( \Delta > 0 \)图像是双曲线
