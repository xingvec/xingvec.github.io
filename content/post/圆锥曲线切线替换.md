# 二次曲线的切线方程——替换法则

## 一、替换法则内容

设二次曲线
$$Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0$$
上有一点 $(x_0, y_0)$，则该点处的**切线方程**可由如下“替换法则”得到：

| 原项 | 替换为 |
|------|--------|
| $Ax^2$ | $Ax_0x$ |
| $Bxy$ | $B\cdot\dfrac{x_0y + y_0x}{2}$ |
| $Cy^2$ | $Cy_0y$ |
| $Dx$ | $D\cdot\dfrac{x + x_0}{2}$ |
| $Ey$ | $E\cdot\dfrac{y + y_0}{2}$ |
| $F$ | $F$ |

即 $(x_0,y_0)$ 处的切线方程为：

$$Ax_0x + B\cdot\frac{x_0y + y_0x}{2} + Cy_0y + D\cdot\frac{x+x_0}{2} + E\cdot\frac{y+y_0}{2} + F = 0$$

## 二、证明思路

利用**隐函数求导**（把 $y$ 视为 $x$ 的函数），求出点 $(x_0,y_0)$ 处的切线斜率 $k$，最后用点斜式化简方程。

### 1. 隐函数求导
对方程 $F(x,y)=0$ 两边关于 $x$ 求导：
$$2Ax + B(y + xy') + 2Cyy' + D + Ey' = 0$$

记 $k = y'$，代入：

$$2Ax + B(y + kx) + 2Cyk + D + Ek = 0$$
$$(Bx + 2Cy + E)\,k = -(2Ax + By + D)$$
### 2. 求点 $(x_0,y_0)$ 处的斜率
$$k = y'\big|_{(x_0,y_0)} = -\frac{2Ax_0 + By_0 + D}{Bx_0 + 2Cy_0 + E}$$
### 3. 点斜式并化简
由 $y - y_0 = k(x - x_0)$，移项得：

$$(y - y_0)(Bx_0 + 2Cy_0 + E) + (x - x_0)(2Ax_0 + By_0 + D) = 0$$

展开：

$$Bx_0y + 2Cy_0y + Ey - Bx_0y_0 - 2Cy_0^2 - Ey_0 + 2Ax_0x + By_0x + Dx - 2Ax_0^2 - Bx_0y_0 - Dx_0 = 0$$

**按 $x$、$y$、常数项重组整理：**
- 含 $x$：$2Ax_0x + By_0x + Dx$
- 含 $y$：$Bx_0y + 2Cy_0y + Ey$
- 常数项：$-Bx_0y_0 - 2Cy_0^2 - Ey_0 - 2Ax_0^2 - Bx_0y_0 - Dx_0$

### 4. 利用点在曲线上的条件
由于 $(x_0, y_0)$ 在曲线上：
$$Ax_0^2 + Bx_0y_0 + Cy_0^2 + Dx_0 + Ey_0 + F = 0$$
即
$$Ax_0^2 + Bx_0y_0 + Cy_0^2 = -(Dx_0 + Ey_0 + F)$$
代入常数项：
$$-(-2Dx_0 - 2Ey_0 - 2F + Dx_0 + Ey_0) = Dx_0 + Ey_0 + 2F$$
### 5. 结论

于是切线方程化为：

$$2Ax_0x + B(x_0y + y_0x) + 2Cy_0y + D(x + x_0) + E(y + y_0) + 2F = 0$$

两边除以 $2$：

$$Ax_0x + B\cdot\frac{x_0y + y_0x}{2} + Cy_0y + D\cdot\frac{x+x_0}{2} + E\cdot\frac{y+y_0}{2} + F = 0$$
**证毕**
